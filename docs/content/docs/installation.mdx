---
title: Installation
description: Package docs for pi-ohm extensions.
---

To install all extensions, run:

```bash
pi install npm:pi-ohm
```

To test the extension, run:

```bash
pi -e npm:pi-ohm
```

To install it locally, run:

```bash
git clone https://github.com/pi-ohm/pi-ohm.git
pi install /path/to/pi-ohm/packages/extension/src/extension.ts
```
